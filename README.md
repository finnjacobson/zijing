# 字境 · Zìjìng

A character-first Chinese reader. Paste text or a vocabulary list; every character opens a study page
with stroke-order animation, readings in six systems and five languages, meanings by reading, common words,
an IDS decomposition tree, its phonetic series, ancient forms, calligraphy styles and handwriting practice.

Fully client-side (Vite + React + TypeScript). Progress is stored in IndexedDB and never leaves the browser.

## Run

```sh
npm install
npm run data        # download sources → data-raw/, build shards → public/data/ (~2 min, ~150 MB)
npm run dev         # http://localhost:5173
npm run build       # → dist/ (static; includes 404.html fallback for /char/… deep links)
```

`npm run data` is three steps that can be rerun separately: `data:download` (cached; `--force` to refetch),
`data:romanization` (Wikipedia table → `src/data/romanization.json`, verified), `data:build` (shards).

## Deploy (GitHub Pages)

`.github/workflows/deploy.yml` builds everything on GitHub and publishes it. It runs on every push to `main`,
weekly (to pick up CC-CEDICT updates), and on demand from the Actions tab.

1. Create the repository on GitHub and push this code.
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. The site appears at `https://<user>.github.io/<repo>/`; the base path is set automatically.
   For a custom domain or a `<user>.github.io` repository, add a repository variable `PAGES_BASE` = `/`.

Data is downloaded and built in CI (about 3–5 minutes), so `public/data/` never goes into git. If the
Wikimedia Commons API rate-limits the runner, the build uses `scripts/fallback/commons-ancient.json`.
License texts for the redistributed data are in `public/licenses/` (see `NOTICE.txt`).

## On the iPad (home-screen app)

字境 is a Progressive Web App. Deploy it to any HTTPS host, open it in Safari, then
Share → **Add to Home Screen**. It opens full-screen with its own icon.

- Everything you open is cached for offline use. Settings → Offline → **Download everything**
  saves all ~54,000 data files (~143 MB) so every character works without a connection.
  The download can be paused and resumed.
- When a new version is deployed, a "Reload" banner appears; offline data is kept across updates.
- Export a JSON backup now and then (Settings or My characters); on iPad it opens the share sheet → Save to Files.

The service worker (`pwa/sw.js`) is only active in production builds, not in `npm run dev`.
Icons are generated by `node scripts/make-icons.mjs` (output is committed in `public/icons/`).

## Tests

With a dev or preview server running on port 5199 (`npx vite --port 5199`):

```sh
node tests/smoke.mjs            # all: reader, character pages, practice/progress/backup
node tests/smoke.mjs reader     # or one group
BASE=http://localhost:5299 node tests/smoke.mjs   # against `vite preview --port 5299`
```

PWA and iPad checks run against a production build (`npm run build && npx vite preview --port 5299`):

```sh
BASE=http://localhost:5299 node tests/pwa.mjs    # install, offline, download/resume, update banner (Chromium)
BASE=http://localhost:5299 node tests/ipad.mjs   # iPad Pro 11 in WebKit: layouts, tap flow, touch handwriting
```

The practice test writes characters by tracing stroke medians with the mouse. Screenshots go to `test-output/`.

## Layout

- `scripts/` — data pipeline (`download.mjs`, `build-romanization.mjs`, `build-data.mjs`)
- `docs/DATA_REPORT.md` — sources, licenses, coverage gaps
- `src/lib/` — data loading, segmentation, pinyin/romanization, T/S conversion, IndexedDB progress
- `src/components/` — stroke animator, practice, decomposition tree, phonetic series, etymology strip, calligraphy, seal
- `src/pages/` — reader, character page, my characters, settings, about/credits

Data licenses and attributions are on the in-app About page and in `docs/DATA_REPORT.md`. CC-CEDICT–derived
data is CC BY-SA 4.0; stroke data is under the Arphic Public License.
